# 错题本

保存未来任务仍成立、能改变决策的用户与项目约定。从具体事件提炼稳定原因和适用边界，避免把 AGENTS.md 变成案例补丁集，也不把规则抽象成“注意质量”一类口号。

## 触发判断

用户表达适用于后续任务的选择、补充稳定项目约束，或同类错误反复发生时，评估是否需要沉淀；不要求用户说明写入位置。隐蔽、代价高只提高复盘优先级，不能单独证明值得写入。

写入 AGENTS.md 前同时确认：

- 有依据：用户明确的长期选择、已核实的项目契约，或有证据支持的共同原因；不从单个案例推定用户的普遍偏好。
- 能持续：在所声明的范围内，更换具体任务、对象或版本后仍成立；短期业务状态、临时路径、一次性绕路不满足此条件。
- 有增量：能改变后续判断，且现有指令没有清楚覆盖，也未被代码、测试或脚本可靠约束。
- 归属正确：跨任务类型成立的用户工作约定，或项目特有的长期契约与决策前提；任务专属要求按下一节归入 Skill。

已有规则清楚但本次漏执行时，检查加载或执行原因，不再追加同义强制语句。证据不足时可以不写，不为完成“记忆”动作制造规则。

## 选择写入位置

先判断原则本身覆盖哪些业务、改变哪些后续任务，再选择存放位置。反馈发生的业务只提供证据；按规则的实际范围匹配已有 Skill。

- 全局 `AGENTS.md`：跨业务、影响多类后续任务的顶层原则、用户偏好和工作约定。先在全局积累；同一方向形成体系并适合独立复用后，再由 `$self-improve-skills` 按治理范围抽取为 Skill。
- 所属 Skill：仅服务特定任务的偏好、文稿体裁要求、平台交付约定、工具用法和操作验证方法；交由 `$self-improve-skills` 维护职责匹配的现有技能。
- 项目 `AGENTS.md`：该项目长期遵守的边界、业务口径、权威来源和必要定位信息。易变事实优先保留稳定来源及何时核验，当前状态留在任务或业务记录中。
- 当前任务：一次性要求、临时状态和未证实的猜测，不提升为长期约定。

同一事件可以产生不同归属的独立结论，例如跨任务交付偏好与实现该偏好的工具步骤；两处各存本职内容，不复制规则，也不相互强制调用。用户明确指定存储位置时尊重其选择。

确认属于 AGENTS.md 后，选择能覆盖该约定的最窄适用范围。优先更新已有且会被加载的文件；项目级通常是仓库根目录，全局级优先现有全局指令文件，找不到时使用 `${CODEX_HOME:-$HOME/.codex}/AGENTS.md`。仅在确有持久规则且没有适用文件时创建。

## 写入规则

先搜索现有约定，优先修正能覆盖同一原因的规则，不按案例逐条追加。写入前做以下判断；遇到抽象层级或归属不清时，读取 [提炼与归属示例](references/rule-quality.md)。

1. 先判断用户希望后续决策发生什么稳定变化，再分清事实、原因和约定；发生过什么不等于以后必须怎样，不把原话直接改写成永久命令。
2. 去掉偶然细节：删去仅用于识别本次事件的 ID、日期、版本或文件名；用户明确指定的对象、稳定契约和不可推导的定位信息可以保留。
3. 写出适用条件、决策原则与必要边界；保留具体可执行的信息，不为追求“宏观”扩大到证据不支持的场景。
4. 用同范围内的另一个任务检验是否仍有用，再检查一个不该适用的场景是否被排除。只救当前单例或过度约束其他任务的规则应重写、缩小范围或不写。

推荐格式：

```markdown
- [主题] 在 <适用条件> 下，优先/应当 <决策或行为原则>；<确有必要的边界>。
```

合并旧规则时保留已有适用边界和明确偏好；不能仅因某条规则具体就删除它。只修改本次相关内容，不顺手清理整个 AGENTS.md。

## 完成后

回读核验改动及适用范围。使用本 Skill 实际更新 AGENTS.md 后，在最终回复中主动给出简短变更摘要，即使记录只是主任务中的附带动作：提供改动文件的可点击链接，说明新增、调整或删除了哪些约定，以及据此提炼的用户要求或事实依据。调整已有约定时说清行为前后变化，不能只说“已记住”或“已更新”。同轮多次修改按最终状态合并回报，便于用户复核并继续调整本元技能。

未写入时说明是已有覆盖、应归 Skill，还是尚不适合长期沉淀，不宣称已更新。不要把错题本变成复盘长文。

## 评测与回归

本技能的 [评测集](evals/cases.json) 保存用于验证归属、长期性和回报的场景，不在普通记忆任务中预加载。用户要求追加案例或运行回归时，按 self-improve-skills 的 [评测流程](../self-improve-skills/references/evaluation.md) 处理；新增题默认完成首次运行；明确要求只保存时暂存。已有题仅在用户明确提出时回归，不因记忆写入、技能修改或时间计划自动重跑。
