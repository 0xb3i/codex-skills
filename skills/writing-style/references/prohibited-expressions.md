# 表达范例

常用表达要求与共同约束见[主文件](../SKILL.md)。需要辨认语境或参考改写时，按问题读取对应小节。原有句式范例依据《行文组织风格.md》§5.1、§5.3、§5.5、§5.6 整理，标题与用语范例沿用原主文件。

## 1. 对比与排比

以下例子将刻意设置的对立改为对象本身的性质。需要纠正误解时，交代原有理解、实际情况与判断依据。

| 反例 | 正例 |
|---|---|
| 这套方案不是离线处理，而是在线处理。 | 这套方案采用在线处理。 |
| 与其说这是一份部署指南，不如说这是一份故障排查手册。 | 这份手册侧重故障排查。 |
| 它不是只记录错误，而是记录全部请求；它不是只保存状态，而是保存完整输入；它不是只显示结果，而是支持重新执行。 | 系统记录全部请求及其完整输入，并支持重新执行请求。 |

原文中的推进方式示例：

> 然而上述梯度并不合理，因为每个动作的梯度都共享了全局的回报 R(τ) 作为系数……因此更合理的做法是为每个动作计算相应的梯度系数。

该例通过原因和解决办法承接判断。

## 2. 术语注释

- 反例：`专家（expert）通过门控（gating）参与计算，并使用负载均衡（load balancing）机制。`
- 正例：`专家通过门控参与计算，并使用负载均衡机制。`
- 反例：在正文或表头写“标准答案（Gold）”，给含义已经清楚的中文名称重复添加英文。
- 正例：直接写“标准答案”；确需辨认生成来源时可写“标准答案（GPT-5.5）”，括号只保留有信息增量的来源名称。
- 反例：`GSB 为 0 / 10 / 1（Good / Same / Bad）`，在已有统一顺序的指标后重复标注名称。
- 正例：已约定按 Good、Same、Bad 顺序书写时，直接写 `GSB 为 0 / 10 / 1。` 比较对象与方向按当前内容交代。
- 需要注释的正例：`研究者开始考虑通过强化微调（Reinforcement Fine-tuning，RFT）适配下游任务。` 后文使用 `RFT`。
- 新人文档反例：直接要求“创建 PPE 后验证改动”，没有说明 PPE 的用途，却给“任务”“代码”等普通词逐个补上英文。
- 新人文档正例：`先创建个人 PPE 泳道，用于独立测试相关功能。`

## 3. 主语与指代

下面的“我们”用于带读者推导或讲解，操作步骤、字段标签和简短状态项可直接说明动作与内容；模型或系统的动作由实际执行者作主语。

- 反例：`先回顾一下 GRPO 的目标函数长什么样。对一组采样回答里的每个 token，它都要算一个比值。`
- 正例：`我们先来回顾一下 GRPO 目标函数的形式。对于一组采样回答中的每个 token，我们都需要计算一个比值。`

## 4. 结尾评价

下例将抽象升华改为具体作用。“原文写的是真好”等简短主观评论不属于强行推导宏大结论。

- 反例：`笔者认为，它真正值得记住的地方并不在公式有多复杂，而在于它提醒了一件常被忽略的事：当一个方法在小规模上好用、放大后却频频出问题时，与其堆补丁，不如先回头问一句，我们是不是在错误的尺度上做了某个本该在另一个尺度上完成的操作。`
- 正例：`正是这一处改动，让重要性采样、clip 和 reward 处在同一个尺度上，有效缓解了大模型 RL 训练不稳定的问题。`

固定对比句式的改写见[对比与排比](#1-对比与排比)。

## 5. 标题命名

案例标题可用编号与分析类型；对象身份参与比较时再带名称，仅区分顺序时只用编号。文档和章节标题与正文要点标签分别处理：要点标签可使用冒号。

- 反例：`总结与思考：推荐系统的本质是一场与算力的讨价还价`
- 正例：`总结与思考`

修改时保留“总结与思考”所表达的章节功能，去掉冒号后的结论。该结论是否成立、如何展开，由正文负责。

## 6. 用语规范

以下对照针对比喻化、夸张或口语缩略表达，说明如何写清动作、状态与程度。

| 反例 | 正例 |
|---|---|
| 把这种波动直接喂进梯度 | 直接将这种波动计入梯度 |
| 把训练不稳定按住 | 缓解训练不稳定 |
| 它既吃不下这些新方法 | 它既无法支持这些新方法 |
| 把计算密度进一步压实 | 进一步提高计算密度 |
| 很多人都撞上了同一堵墙 | 很多人都遇到了同样的问题 |
| token 比值随之剧烈跳动 | token 比值随之大幅波动 |
| 概率出现突变 | 概率明显变化 |
| 上一级交来的候选 | 上一级传递来的候选 |
| 把序列送进模型走一遍前向 | 将序列输入模型，再进行一遍前向计算 |
| 对 logits 跑个 softmax | 对 logits 计算 softmax |
| 能力提升靠堆参数堆出来的 | 能力提升得益于参数量的扩展 |
| 一到大模型就这么脆 | 一到大模型就这么不稳定 |

对照表对应修辞语境，替换时保留原文程度。若“突变”等词描述的是有依据的技术性质，保留该性质；用于解释抽象概念、确实能降低理解难度的功能性类比可保留。
