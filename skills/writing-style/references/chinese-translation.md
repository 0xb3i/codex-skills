# 中文翻译

适用于外语资料翻译成中文、润色译文，以及为这些任务编写翻译提示词。翻译须忠实保留原文信息，不能套用创作规则删掉原文中的作者声明、比较或必要解释。

- 按中文语序清楚表达对象、动作和条件；将多层从句与修饰拆成相互衔接的短句，避免逗号串联多个完整判断，也不机械按字数切句。
- 用常见、具体的词语，减少欧化句式、抽象名词堆叠和过度书面化的表述。平实不等于俚语化，通俗不等于省略技术含义。
- 拆句与调整语序后，核对主语、指代、否定、条件、因果、比较及不确定性；事实、数字、单位、代码、链接和原有结构保持完整。不得把全文翻译改成摘要，或补入来源没有的解释。
- 术语使用准确、通行的中文译法，保留必要专名与代码标识；同一概念称呼一致，不反复添加英文括注。
- 例：“在具备充分条件的情况下，系统能够对该操作予以执行。”可改为“条件满足时，系统就可以执行这个操作。”信息保留而语序、用词更自然；不能简化成无条件的“系统可以执行”。
- 修改模型翻译提示词时，用未写进提示词的真实原文核验：长句是否更易读、原意是否完整、专业术语是否准确；多入口共用一套表达规则，分别保留各自输出格式。
